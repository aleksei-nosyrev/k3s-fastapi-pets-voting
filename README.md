# 🐱 Отказоустойчивое приложение голосования "Котики против Собачек" 🐶

Локальное веб-приложение с микросервисной архитектурой, написанное на **Python (FastAPI)** и **PostgreSQL**, развернутое в легковесном кластере **Kubernetes (K3s)** внутри подсистемы **WSL2 (Ubuntu)** на Windows 11.

## 🛠️ Архитектура и технологии
- **Бэкенд:** Python 3.11, FastAPI, Uvicorn, Psycopg3.
- **Фронтенд:** Чистый HTML5, CSS3, JavaScript (асинхронные запросы Fetch API, автообновление результатов по инкременту).
- **База данных:** PostgreSQL 15 (развернута в кластере с PersistentVolume, данные физически зафиксированы на хост-машине).
- **Инфраструктура и оркестрация:** K3s (Kubernetes), Traefik Ingress Controller для внешней маршрутизации домена `pets.local`.
- **Контейнеризация:** Docker (мультистадийная сборка, оптимизация слоев кэширования).
- **Безопасность:** Интегрирован **Rate-Limiting (Анти-спам)** на основе фиксации IP-адресов пользователей через СУБД (блокировка повторного голоса на 10 секунд с кодом ответа `429 Too Many Requests`).

## 🚀 Как развернуть проект локально

1. Убедитесь, что у вас запущен кластер K3s / Minikube.
2. Клонируйте репозиторий:
   ```bash
   git clone https://github.com/aleksei-nosyrev/k3s-fastapi-pets-voting
   cd k3s-fastapi-pets-voting
   ```
3. Создайте локальный файл секретов `db-secret.yaml` (исключен из репозитория) с вашими base64-паролями для PostgreSQL.
4. Разверните всю инфраструктуру одной командой:
   ```bash
   kubectl apply -f .
   ```
5. Пропишите IP-адрес шлюза Ingress в системный файл `hosts` вашей операционной системы для домена `pets.local`.
6. Открывайте в браузере `http://pets.local` для голосования или `http://pets.local/docs` для интерактивного тестирования Swagger API!
